## What Is a Hash Map and Why Should You Care?

Imagine you have a massive phone book with 10,000 names. If the names are in random order, finding someone means checking every single entry — that's slow! But if you have an index where you can jump directly to the right page using someone's name, that's instant.

A **hash map** works like that index. It stores **key-value pairs** and lets you look up any value by its key in O(1) time — essentially instant, no matter how big the data is.

In Python, hash maps are called **dictionaries** (`dict`). You've probably seen them before:

- `{"apple": 3, "banana": 5}` — the fruits are **keys**, the numbers are **values**
- You can check if a key exists, add new pairs, or retrieve values — all in O(1) time

This is a game-changer for LeetCode because many problems that seem to require nested loops (O(n²)) can be solved in a single pass using a hash map.

## Hash Map Basics in Python

```python
# Creating a dictionary
fruits = {"apple": 3, "banana": 5, "cherry": 2}

# Accessing a value by key — O(1)
print(fruits["apple"])  # Output: 3

# Checking if a key exists — O(1)
print("banana" in fruits)  # Output: True
print("grape" in fruits)   # Output: False

# Adding a new key-value pair — O(1)
fruits["grape"] = 7

# Updating a value
fruits["apple"] = fruits["apple"] + 1  # Now apple is 4

# Looping through all keys
for fruit in fruits:
    print(f"{fruit}: {fruits[fruit]}")

# Using .get() to avoid errors when key doesn't exist
print(fruits.get("mango", 0))  # Output: 0 (default value)
```

## The Classic Problem: Two Sum (Revisited with Hash Maps)

In Lesson 3, you may have seen the Two Sum problem solved with nested loops. Let's see why that's slow and how a hash map fixes it.

**Problem:** Given an array of numbers and a target, find two numbers that add up to the target. Return their indices.

**The slow approach (O(n²)):** For each number, loop through every other number to check if they add up to the target. With 10,000 numbers, that's 100,000,000 checks!

**The hash map approach (O(n)):** As you walk through the array, for each number ask: *"Have I already seen the number that would complete the pair?"* Store each number you've visited in a hash map so you can check instantly.

Think of it like this: You're at a dance, looking for a partner whose height plus yours equals 10 feet. Instead of asking every person in the room, you write your height on a board. When someone new arrives, they check the board to see if their perfect partner already signed up.

## Two Sum — Hash Map Solution

```python
def two_sum(nums, target):
    # This hash map stores {number: its index}
    seen = {}
    
    for i in range(len(nums)):
        complement = target - nums[i]  # What number do I need?
        
        if complement in seen:         # Have I seen it before? O(1) check!
            return [seen[complement], i]
        
        seen[nums[i]] = i              # Remember this number and its index
    
    return []  # No solution found

# Example walkthrough with nums = [2, 7, 11, 15], target = 9
# 
# Step 0: nums[0]=2, complement=7, seen={} → 7 not in seen → seen={2:0}
# Step 1: nums[1]=7, complement=2, seen={2:0} → 2 IS in seen! → return [0, 1]

print(two_sum([2, 7, 11, 15], 9))   # Output: [0, 1]
print(two_sum([3, 2, 4], 6))         # Output: [1, 2]
print(two_sum([3, 3], 6))            # Output: [0, 1]
```

## Common Hash Map Patterns on LeetCode

Hash maps appear in many problem types. Here are the most common patterns you'll encounter:

**1. Counting Frequency**
Count how many times each element appears. This is useful for finding duplicates, most common elements, or checking if two strings are anagrams.

```python
def count_frequency(nums):
    freq = {}
    for num in nums:
        freq[num] = freq.get(num, 0) + 1
    return freq

# [1, 2, 2, 3, 3, 3] → {1: 1, 2: 2, 3: 3}
```

**2. Quick Lookup (like Two Sum)**
Store previously seen values so you can check for matches in O(1).

**3. Grouping**
Group items that share a common property using lists as values.

```python
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
groups = {}
for word in words:
    key = ''.join(sorted(word))  # "eat" → "aet", "tea" → "aet"
    if key not in groups:
        groups[key] = []
    groups[key].append(word)
# Result: {"aet": ["eat", "tea", "ate"], "ant": ["tan", "nat"], "abt": ["bat"]}
```

**When to reach for a hash map:** Whenever you think "I need to check if I've seen this before" or "I need to count things" — a hash map is almost always the answer.

## Key Takeaways

- Hash maps (Python dicts) give you O(1) lookup, insertion, and existence checks — making them essential for efficient solutions.
- The 'complement lookup' pattern (as in Two Sum) converts O(n²) brute force into O(n) by remembering what you've already seen.
- Use `dict.get(key, default)` to safely access values without crashing when a key doesn't exist.
- Frequency counting with hash maps is a foundational pattern that appears in dozens of LeetCode problems.
- Whenever a problem involves finding pairs, counting occurrences, or grouping items, think hash map first.
