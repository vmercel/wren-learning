## Quick Recap: Hash Maps as Lookup Tools

In lesson 13, we used hash maps (dictionaries) to quickly look up values — specifically for the Two Sum problem where we checked if a complement existed. Today, we unlock a second superpower of hash maps: **counting things**.

Imagine you're a teacher counting votes for class president. Instead of scanning the entire list of votes every time someone asks "how many votes does Alex have?", you keep a tally sheet. Each time you see a name, you add a mark next to it. That tally sheet is exactly what a hash map does when we use it for counting.

## The Problem: Majority Element (LeetCode #169)

**Problem:** Given an array `nums` of size `n`, return the element that appears more than `n // 2` times. You may assume a majority element always exists.

**Examples:**
- `[3, 2, 3]` → `3` (appears 2 times out of 3, and 2 > 3//2 = 1)
- `[2, 2, 1, 1, 1, 2, 2]` → `2` (appears 4 times out of 7, and 4 > 7//2 = 3)

**Why this matters:** Counting occurrences in a collection is something you'll do constantly — in data analysis, log processing, feature engineering, and dozens of interview problems. The pattern you learn here will become second nature.

## Approach 1: The Brute Force Way

The most straightforward idea: for each unique element, count how many times it appears by scanning the whole array.

**Steps:**
1. For each element in the array
2. Count how many times it appears (inner loop)
3. If that count is more than `n // 2`, return it

**Time complexity:** O(n²) — for every element, we scan the whole array again.

This works, but it's slow. Let's do better with a hash map.

## Approach 2: Hash Map Counting (Optimal and Intuitive)

```python
def majorityElement(nums):
    # Step 1: Create our "tally sheet"
    counts = {}  # key = number, value = how many times we've seen it
    
    # Step 2: Walk through the array, counting each element
    for num in nums:
        if num in counts:
            counts[num] += 1  # Seen before — add a tally mark
        else:
            counts[num] = 1   # First time seeing it — start at 1
    
    # Step 3: Find the element with the highest count
    # (or the one that exceeds n // 2)
    threshold = len(nums) // 2
    for num, count in counts.items():
        if count > threshold:
            return num

# Test it out
print(majorityElement([3, 2, 3]))              # Output: 3
print(majorityElement([2, 2, 1, 1, 1, 2, 2]))  # Output: 2
print(majorityElement([1]))                     # Output: 1
```

## Let's Trace Through Step by Step

**Input:** `[2, 2, 1, 1, 1, 2, 2]`

**Building the counts dictionary:**

| Step | num | counts so far |
|------|-----|---------------|
| 1 | 2 | `{2: 1}` |
| 2 | 2 | `{2: 2}` |
| 3 | 1 | `{2: 2, 1: 1}` |
| 4 | 1 | `{2: 2, 1: 2}` |
| 5 | 1 | `{2: 2, 1: 3}` |
| 6 | 2 | `{2: 3, 1: 3}` |
| 7 | 2 | `{2: 4, 1: 3}` |

**Checking the threshold:** `n // 2 = 7 // 2 = 3`
- Is `4 > 3`? Yes! Return `2`.

**Time complexity:** O(n) — one pass to count, one pass to check.
**Space complexity:** O(n) — we store counts for each unique element.

## Cleaner Version Using Python's get() and Early Exit

```python
def majorityElement(nums):
    counts = {}
    threshold = len(nums) // 2
    
    for num in nums:
        # .get(num, 0) returns 0 if num isn't in the dict yet
        counts[num] = counts.get(num, 0) + 1
        
        # Check immediately — we can exit early!
        if counts[num] > threshold:
            return num

# This version is slightly faster because it can stop
# before reading the entire array
print(majorityElement([2, 2, 1, 1, 1, 2, 2]))  # Output: 2

# ---- BONUS: Python's collections.Counter ----
from collections import Counter

def majorityElement_counter(nums):
    counts = Counter(nums)  # Counts everything in one line!
    threshold = len(nums) // 2
    for num, count in counts.items():
        if count > threshold:
            return num

print(majorityElement_counter([3, 2, 3]))  # Output: 3
```

## The Counting Pattern — Your New Template

You'll use this pattern over and over. Here's the general template:

```
1. Create an empty dictionary (counts = {})
2. Loop through your data
3. For each item, increment its count
4. Use the counts to answer the question
```

**Common variations you'll encounter:**
- Find the most frequent element → same as today
- Find elements that appear exactly k times → filter counts
- Check if two strings are anagrams → count letters in both, compare
- Find the first unique character → count, then find count == 1

The `.get(key, default)` trick is worth memorizing:
- `counts.get(num, 0) + 1` replaces the if/else block entirely
- It says: "get the value for `num`, or use `0` if it doesn't exist"

## Key Takeaways

- Hash maps have two main superpowers: fast lookup (lesson 13) and efficient counting (today). Both run in O(n) time.
- The counting pattern — create dict, loop, increment, analyze — is a template you'll reuse in dozens of problems.
- Use .get(key, default) to handle the 'first time seeing this element' case cleanly in one line.
- Adding an early exit check inside the counting loop can make your solution even faster in practice.
- Python's collections.Counter is a shortcut for counting, but understanding the manual approach is essential for interviews.
