## What Is a Stack?

Imagine a stack of plates in a cafeteria. You can only:

- **Put a plate on top** (called **push**)
- **Take a plate off the top** (called **pop**)

You can't pull a plate from the middle or bottom — you always work with the **top** item. This is called **Last In, First Out (LIFO)**.

In Python, we use a regular list as a stack:
- `stack.append(item)` → push (add to top)
- `stack.pop()` → pop (remove from top)
- `stack[-1]` → peek (look at top without removing)
- `len(stack) == 0` → check if empty

## Understanding the Problem: Valid Parentheses (LeetCode #20)

**Problem:** Given a string containing just the characters `(`, `)`, `{`, `}`, `[`, and `]`, determine if the input string is valid.

A string is valid if:
1. Every opening bracket has a **matching closing bracket** of the same type
2. Brackets are closed in the **correct order** (no overlapping)
3. Every closing bracket has a corresponding opening bracket

**Examples:**
- `"()"` → ✅ Valid
- `"()[]{}"` → ✅ Valid
- `"(]"` → ❌ Invalid (wrong type)
- `"([)]"` → ❌ Invalid (wrong order — they overlap)
- `"{[]}"` → ✅ Valid (nested correctly)

**Why is this hard without a stack?** Consider `"([)]"`. The `)` closes before the `]`, but `[` was opened after `(`. They're crossing over each other like tangled wires. A stack naturally tracks the **most recently opened** bracket, making it easy to check if things close in the right order.

## The Strategy: Think Like a Plate Stacker

Here's the approach, step by step:

1. **Walk through each character** in the string
2. If it's an **opening bracket** (`(`, `[`, `{`), **push** it onto the stack
3. If it's a **closing bracket** (`)`, `]`, `}`):
   - Check if the stack is **empty** → if so, there's no matching opener → ❌ Invalid
   - **Pop** the top of the stack and check if it **matches** the closing bracket
   - If it doesn't match → ❌ Invalid
4. After processing all characters, the stack should be **empty**
   - If items remain, some brackets were never closed → ❌ Invalid

**Walkthrough with `"{[]}"`:**

| Step | Char | Action | Stack |
|------|------|--------|-------|
| 1 | `{` | Push | `['{']` |
| 2 | `[` | Push | `['{', '[']` |
| 3 | `]` | Pop `[`, matches `]` ✅ | `['{']` |
| 4 | `}` | Pop `{`, matches `}` ✅ | `[]` |

Stack is empty → ✅ **Valid!**

## The Solution in Python

```python
def isValid(s: str) -> bool:
    # Map each closing bracket to its matching opening bracket
    matching = {
        ')': '(',
        ']': '[',
        '}': '{'
    }
    
    stack = []
    
    for char in s:
        if char in matching:
            # It's a closing bracket
            # Check if stack is empty or top doesn't match
            if not stack or stack[-1] != matching[char]:
                return False
            stack.pop()  # Remove the matched opening bracket
        else:
            # It's an opening bracket — push onto stack
            stack.append(char)
    
    # Valid only if all brackets were matched (stack is empty)
    return len(stack) == 0

# Test cases
print(isValid("()"))       # True
print(isValid("()[]{}"))   # True
print(isValid("(]"))       # False
print(isValid("([)]"))     # False
print(isValid("{[]}"))     # True
print(isValid("("))        # False (unclosed)
print(isValid(")"))        # False (no opener)
print(isValid(""))         # True (empty string is valid)
```

## Breaking Down the Code and Complexity

**Key design choice:** We use a dictionary (`matching`) that maps closing brackets to their opening counterparts. When we see `)`, we look up that it should match `(`. This is cleaner than writing multiple if-else statements.

**The `if char in matching` trick:** Since our dictionary only has closing brackets as keys, this check tells us whether the character is a closing bracket.

**Edge cases handled:**
- Empty string → stack stays empty → returns `True`
- Only opening brackets like `"((("` → stack has items left → returns `False`
- Starts with closing bracket like `")"` → stack is empty when we try to match → returns `False`

**Time Complexity:** O(n) — we visit each character exactly once
**Space Complexity:** O(n) — in the worst case (all opening brackets), the stack holds every character

**Compared to our previous problems:**
- Lessons 1-4 used simple variables and hash maps
- Lesson 5 introduced string manipulation techniques
- This lesson introduces our **first data structure-based approach** — using a stack to track state as we process a sequence

## Key Takeaways

- A stack is a Last In, First Out (LIFO) structure — like a stack of plates, you always work with the top item. In Python, use a list with append() and pop().
- The Valid Parentheses problem is THE classic stack problem. The key insight is that the most recently opened bracket must be closed first, which is exactly what a stack tracks.
- Always handle edge cases: empty stack when you encounter a closing bracket, and leftover items in the stack after processing all characters.
- Using a dictionary to map closing brackets to opening brackets makes the code clean and easily extendable to new bracket types.
