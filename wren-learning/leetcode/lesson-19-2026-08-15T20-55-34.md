## Quick Recap: From DFS to BFS

In Lesson 18, we learned about binary trees and used **Depth-First Search (DFS)** — we went as deep as possible down one branch before backtracking. Think of DFS like exploring a cave system by going as far into one tunnel as you can before turning back.

Today we learn **Breadth-First Search (BFS)** — instead of going deep, we explore **all nodes at the current depth** before moving to the next level. Think of it like reading a book page by page, or how ripples spread outward from a stone dropped in water.

**When to use BFS over DFS:**
- When you need to process nodes **level by level**
- When you need the **shortest path** in an unweighted structure
- When you need to find something **close to the root** first

## The Queue: BFS's Secret Weapon

BFS uses a **queue** — a First-In, First-Out (FIFO) data structure. Think of it like a line at a coffee shop: the first person in line gets served first.

**How BFS works step by step:**
1. Put the root node into the queue
2. While the queue is not empty:
   - Count how many nodes are at this level (the current queue size)
   - Process all those nodes one by one
   - For each node, add its children to the **back** of the queue
3. The children we just added become the next level

In Python, we use `collections.deque` as our queue because it gives us O(1) operations for adding to the back and removing from the front.

```
Level 0:       3          Queue starts: [3]
Level 1:     9   20       After level 0: [9, 20]
Level 2:       15   7     After level 1: [15, 7]

Result: [[3], [9, 20], [15, 7]]
```

## The Problem: LeetCode 102 — Binary Tree Level Order Traversal

**Problem:** Given the root of a binary tree, return the level order traversal of its nodes' values (i.e., from left to right, level by level).

**Example:**
- Input: root = [3, 9, 20, null, null, 15, 7]
- Output: [[3], [9, 20], [15, 7]]

**Breaking it down:**
- We need to return a **list of lists** — each inner list contains all values at one level
- We need to know when one level ends and the next begins
- The trick: at the start of processing each level, the queue contains **exactly** the nodes for that level

## Solution: BFS with a Queue

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def levelOrder(root):
    # Edge case: empty tree
    if not root:
        return []
    
    result = []          # This will hold all levels
    queue = deque([root]) # Start with the root in our queue
    
    while queue:
        level_size = len(queue)  # How many nodes at THIS level?
        current_level = []       # Collect values for this level
        
        # Process exactly 'level_size' nodes (one full level)
        for i in range(level_size):
            node = queue.popleft()          # Remove from front
            current_level.append(node.val)  # Record value
            
            # Add children to back of queue (they're next level)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(current_level)  # Save this level
    
    return result

# Build the example tree:  3 -> (9, 20), 20 -> (15, 7)
root = TreeNode(3)
root.left = TreeNode(9)
root.right = TreeNode(20)
root.right.left = TreeNode(15)
root.right.right = TreeNode(7)

print(levelOrder(root))  # [[3], [9, 20], [15, 7]]
```

## Walking Through the Algorithm Step by Step

Let's trace through with our example tree:

**Initial state:** queue = [3], result = []

**Iteration 1 (Level 0):**
- level_size = 1 (one node at this level)
- Process node 3: current_level = [3]
- Add children 9 and 20 to queue
- queue = [9, 20], result = [[3]]

**Iteration 2 (Level 1):**
- level_size = 2 (two nodes at this level)
- Process node 9: current_level = [9], no children to add
- Process node 20: current_level = [9, 20], add children 15 and 7
- queue = [15, 7], result = [[3], [9, 20]]

**Iteration 3 (Level 2):**
- level_size = 2
- Process node 15: current_level = [15], no children
- Process node 7: current_level = [15, 7], no children
- queue = [] (empty!), result = [[3], [9, 20], [15, 7]]

**Queue is empty → we're done!**

**Complexity:**
- **Time:** O(n) — we visit every node exactly once
- **Space:** O(n) — the queue can hold up to n/2 nodes (the widest level)

## Key Takeaways

- BFS explores a tree level by level using a queue (FIFO), unlike DFS which goes depth-first using recursion or a stack
- The key trick for level order traversal: at each step, snapshot the queue size — that tells you exactly how many nodes belong to the current level
- Use collections.deque in Python for efficient queue operations — popleft() is O(1) compared to list.pop(0) which is O(n)
- BFS is your go-to approach when a problem mentions 'level by level', 'layer by layer', 'shortest path', or 'minimum depth'
