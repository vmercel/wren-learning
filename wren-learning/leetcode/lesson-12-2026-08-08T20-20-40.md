## Why Hash Maps Are a Game-Changer

Imagine you have a phone book with 10,000 names. To find someone's number:

- **Without a hash map**: You flip through every page one by one — this is O(n)
- **With a hash map**: You jump directly to the right page — this is O(1)

A **hash map** (called a `dictionary` or `dict` in Python) stores **key-value pairs**. You give it a key, and it instantly gives you the value. No searching required.

```
phone_book = {"Alice": "555-1234", "Bob": "555-5678"}
print(phone_book["Alice"])  # Instantly returns "555-1234"
```

In LeetCode problems, hash maps help you:
- **Remember things you've already seen** (avoiding repeated work)
- **Count occurrences** of elements
- **Create instant lookups** instead of nested loops

## Hash Map Basics in Python

Here are the essential dictionary operations you need:

| Operation | Code | Time |
|-----------|------|------|
| Create empty | `d = {}` | O(1) |
| Add/update | `d[key] = value` | O(1) |
| Look up | `d[key]` or `d.get(key, default)` | O(1) |
| Check if key exists | `key in d` | O(1) |
| Delete | `del d[key]` | O(1) |
| Get all keys | `d.keys()` | O(n) |
| Get all values | `d.values()` | O(n) |

**Important tip**: Use `d.get(key, default)` instead of `d[key]` to avoid errors when the key doesn't exist.

```python
counts = {}
word = "hello"
for char in word:
    counts[char] = counts.get(char, 0) + 1
# Result: {'h': 1, 'e': 1, 'l': 2, 'o': 1}
```

## LeetCode Problem: Two Sum (Problem #1)

This is literally the most famous LeetCode problem, and hash maps make it elegant.

**Problem**: Given an array of numbers and a target, return the **indices** of two numbers that add up to the target. Assume exactly one solution exists.

**Example**: `nums = [2, 7, 11, 15]`, `target = 9` → Return `[0, 1]` because `nums[0] + nums[1] = 2 + 7 = 9`

**The slow way (brute force)**: Check every pair with two nested loops — O(n²)

**The fast way (hash map)**: For each number, ask: *"Have I already seen the number that would complete this pair?"*

Think of it like this: You're at a dance, looking for a partner who is exactly the right height to reach a shelf together. Instead of asking everyone twice, you keep a list of people you've already met. When a new person arrives, you check your list for their perfect match.

## Two Sum — Brute Force vs. Hash Map Solution

```python
# SLOW: Brute force — O(n²) time
def two_sum_brute(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []

# FAST: Hash map — O(n) time
def two_sum(nums, target):
    seen = {}  # Maps number -> its index
    
    for i, num in enumerate(nums):
        complement = target - num  # What number do I need?
        
        if complement in seen:     # Have I seen it before?
            return [seen[complement], i]
        
        seen[num] = i              # Remember this number and its index
    
    return []

# Walk through: nums = [2, 7, 11, 15], target = 9
# Step 0: num=2, complement=7, seen={} → 7 not in seen → seen={2:0}
# Step 1: num=7, complement=2, seen={2:0} → 2 IS in seen! → return [0, 1] ✓

print(two_sum([2, 7, 11, 15], 9))   # [0, 1]
print(two_sum([3, 2, 4], 6))        # [1, 2]
print(two_sum([3, 3], 6))           # [0, 1]
```

## Bonus Pattern: Counting with Hash Maps

```python
# Problem: Check if two strings are anagrams (LeetCode #242)
# Anagrams use the same letters the same number of times
# "listen" and "silent" are anagrams

def is_anagram(s, t):
    if len(s) != len(t):
        return False
    
    # Count every character in both strings
    count_s = {}
    count_t = {}
    
    for char in s:
        count_s[char] = count_s.get(char, 0) + 1
    
    for char in t:
        count_t[char] = count_t.get(char, 0) + 1
    
    return count_s == count_t  # Python can compare dicts directly!

print(is_anagram("listen", "silent"))  # True
print(is_anagram("hello", "world"))   # False
print(is_anagram("rat", "car"))       # False

# Even cleaner with a single hash map:
def is_anagram_v2(s, t):
    if len(s) != len(t):
        return False
    
    counts = {}
    for char in s:
        counts[char] = counts.get(char, 0) + 1  # Add for s
    for char in t:
        counts[char] = counts.get(char, 0) - 1  # Subtract for t
    
    # If anagram, all counts should be 0
    return all(v == 0 for v in counts.values())

print(is_anagram_v2("anagram", "nagaram"))  # True
```

## Key Takeaways

- Hash maps (Python dicts) give you O(1) lookup, insert, and delete — making them perfect for replacing nested loops
- The 'complement pattern' (used in Two Sum) is one of the most common hash map techniques: store what you've seen, check if the missing piece exists
- Counting character or element frequencies with a hash map is a foundational pattern that appears in dozens of LeetCode problems
- When you see a problem requiring O(n²) with nested loops, ask yourself: 'Can a hash map help me avoid the inner loop?'
- Use dict.get(key, default) to safely access keys without causing KeyError exceptions
