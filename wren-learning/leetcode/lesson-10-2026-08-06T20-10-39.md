## What Is a Stack?

Imagine a stack of plates in a cafeteria. You can only:

- **Put a plate on top** (called **push**)
- **Take the top plate off** (called **pop**)
- **Look at the top plate** (called **peek**)

You can't pull a plate from the middle or bottom — only the top. This is called **Last In, First Out (LIFO)**: the last thing you added is the first thing you remove.

In Python, a regular list works perfectly as a stack:
- `stack.append(item)` → push
- `stack.pop()` → pop
- `stack[-1]` → peek

### Why Do Stacks Matter for LeetCode?

Stacks are perfect when you need to:
- **Match pairs** (like parentheses)
- **Track what came before** (like undo/redo)
- **Process things in reverse order**
- **Keep a running history** that you peel back layer by layer

Many medium and hard LeetCode problems use stacks. Mastering them now gives you a huge advantage.

## Stack Basics in Python

```python
# A stack is just a list used in a specific way
stack = []

# Push items onto the stack
stack.append('A')
stack.append('B')
stack.append('C')
print(stack)  # ['A', 'B', 'C'] — C is on top

# Peek at the top item (without removing it)
top = stack[-1]
print(f"Top item: {top}")  # Top item: C

# Pop the top item off
removed = stack.pop()
print(f"Removed: {removed}")  # Removed: C
print(stack)  # ['A', 'B'] — now B is on top

# Check if stack is empty
if not stack:
    print("Stack is empty")
else:
    print(f"Stack has {len(stack)} items")  # Stack has 2 items
```

## Today's Problem: Valid Parentheses (LeetCode #20)

**Problem:** Given a string containing only the characters `(`, `)`, `{`, `}`, `[`, `]`, determine if the input string is valid.

A string is valid if:
1. Every opening bracket has a matching closing bracket
2. Brackets are closed in the **correct order** (no crossing)
3. Every closing bracket has a corresponding opening bracket

**Examples:**
- `"()"` → `True` ✅
- `"()[]{}"` → `True` ✅
- `"(]"` → `False` ❌ (wrong type)
- `"([)]"` → `False` ❌ (wrong order — they cross!)
- `"{[]}"` → `True` ✅ (nested correctly)

### Why Is This a Stack Problem?

Think about it: when you see a closing bracket `)`, it needs to match the **most recent** unmatched opening bracket. "Most recent" = last in, first out = **stack!**

### The Strategy:
1. Walk through each character
2. If it's an **opening bracket**, push it onto the stack
3. If it's a **closing bracket**, check if the top of the stack is the matching opener
   - If yes, pop the opener off (they're matched!)
   - If no, the string is invalid
4. At the end, the stack should be empty (all brackets matched)

## Solution: Valid Parentheses

```python
def isValid(s: str) -> bool:
    # Map each closing bracket to its matching opening bracket
    matching = {
        ')': '(',
        ']': '[',
        '}': '{'
    }
    
    stack = []
    
    for char in s:
        if char in matching:
            # It's a closing bracket — check if it matches the top
            if stack and stack[-1] == matching[char]:
                stack.pop()  # Match found! Remove the opener
            else:
                return False  # No match — invalid!
        else:
            # It's an opening bracket — push onto stack
            stack.append(char)
    
    # If stack is empty, all brackets were matched
    return len(stack) == 0

# Test cases
print(isValid("()"))      # True
print(isValid("()[]{}"))  # True
print(isValid("(]"))      # False
print(isValid("([)]"))    # False
print(isValid("{[]}"))    # True
print(isValid("("))       # False — unmatched opener
print(isValid(")"))       # False — closing with empty stack
```

## Walking Through the Solution Step by Step

Let's trace through `"{[]}"` to see the stack in action:

| Step | Char | Action | Stack After |
|------|------|--------|-------------|
| 1 | `{` | Opening → push | `['{']` |
| 2 | `[` | Opening → push | `['{', '[']` |
| 3 | `]` | Closing → top is `[` → match! Pop | `['{']` |
| 4 | `}` | Closing → top is `{` → match! Pop | `[]` |

Stack is empty → **return True** ✅

Now let's trace `"([)]"` (the tricky one):

| Step | Char | Action | Stack After |
|------|------|--------|-------------|
| 1 | `(` | Opening → push | `['(']` |
| 2 | `[` | Opening → push | `['(', '[']` |
| 3 | `)` | Closing → top is `[` → NOT `(` | — |

Mismatch → **return False** ❌

The brackets *cross* each other, and the stack catches this perfectly!

### Complexity Analysis:
- **Time: O(n)** — we look at each character once
- **Space: O(n)** — in the worst case (all openers), the stack holds every character

## Key Takeaways

- A stack is a Last In, First Out (LIFO) structure — in Python, just use a list with append() and pop()
- Stacks are the go-to data structure whenever you need to match pairs, track history, or process things in reverse order
- Valid Parentheses is solved by pushing openers onto a stack and checking that each closer matches the top — this O(n) pattern appears in many LeetCode problems
- Always check edge cases with stacks: what if the stack is empty when you try to pop? What if items remain at the end?
