## Why Hash Maps Are a Game-Changer

Imagine you have a phone book with 10,000 names. To find someone's number:

- **Without a hash map**: You scan every single entry one by one — this takes O(n) time
- **With a hash map**: You jump directly to the right entry — this takes O(1) time

A **hash map** is like a magical filing cabinet where you can instantly find anything by its label. In Python, we call them **dictionaries** (`dict`).

In previous lessons, we often used nested loops (O(n²)) to search for things. Hash maps let us trade a little extra memory for dramatically faster lookups. This single idea solves a huge percentage of LeetCode problems.

## Hash Map Basics in Python

Here's what you need to know about Python dictionaries:

- **Creating**: `my_map = {}` or `my_map = dict()`
- **Adding**: `my_map[key] = value`
- **Checking if a key exists**: `if key in my_map:`
- **Getting a value**: `my_map[key]` or `my_map.get(key, default)`
- **Deleting**: `del my_map[key]`

Keys can be strings, numbers, or tuples. Values can be anything.

**Common patterns:**
1. **Counting occurrences** — How many times does each item appear?
2. **Storing complements** — What value do I need to complete a pair?
3. **Tracking indices** — Where did I last see this value?
4. **Grouping items** — Which items belong together?

## Pattern 1: Counting with a Hash Map

```python
# Problem: Given a string, find the first character that doesn't repeat.
# Example: "leetcode" -> "l" (because 'l' appears only once and comes first)

def first_unique_char(s):
    # Step 1: Count every character
    char_count = {}
    for char in s:
        if char in char_count:
            char_count[char] += 1
        else:
            char_count[char] = 1
    
    # Step 2: Find the first one with count == 1
    for i, char in enumerate(s):
        if char_count[char] == 1:
            return i
    
    return -1  # No unique character found

# Test it
print(first_unique_char("leetcode"))   # 0 (the 'l')
print(first_unique_char("aabb"))       # -1 (no unique chars)
print(first_unique_char("loveleetcode"))  # 2 (the 'v')

# Without a hash map, we'd need nested loops: O(n²)
# With a hash map: O(n) — we scan the string just twice!
```

## Pattern 2: Revisiting Two Sum with a Hash Map

```python
# Remember Two Sum from Lesson 2? Let's see the hash map approach.
# Problem: Find two numbers in an array that add up to a target.

def two_sum(nums, target):
    # This map stores: number -> its index
    seen = {}
    
    for i, num in enumerate(nums):
        complement = target - num  # What number do I need?
        
        if complement in seen:     # Have I seen it before?
            return [seen[complement], i]
        
        seen[num] = i              # Remember this number and where it was
    
    return []  # No solution found

# Walk through: nums = [2, 7, 11, 15], target = 9
# i=0, num=2: complement=7, seen={} -> not found, seen={2:0}
# i=1, num=7: complement=2, seen={2:0} -> FOUND! return [0, 1]

print(two_sum([2, 7, 11, 15], 9))   # [0, 1]
print(two_sum([3, 2, 4], 6))        # [1, 2]

# Brute force: O(n²) with nested loops
# Hash map: O(n) with a single pass!
```

## LeetCode #242: Valid Anagram

```python
# Problem: Given two strings s and t, return True if t is an anagram of s.
# An anagram uses the exact same letters, just rearranged.
# Example: "anagram" and "nagaram" -> True
# Example: "rat" and "car" -> False

def is_anagram(s, t):
    # If lengths differ, can't be anagrams
    if len(s) != len(t):
        return False
    
    # Count characters in s
    count = {}
    for char in s:
        count[char] = count.get(char, 0) + 1
    
    # Subtract characters in t
    for char in t:
        if char not in count:
            return False  # t has a letter s doesn't
        count[char] -= 1
        if count[char] < 0:
            return False  # t has more of this letter than s
    
    return True

# Test
print(is_anagram("anagram", "nagaram"))  # True
print(is_anagram("rat", "car"))          # False
print(is_anagram("aacc", "ccac"))        # False

# Bonus: Python shortcut using Counter
from collections import Counter

def is_anagram_short(s, t):
    return Counter(s) == Counter(t)

print(is_anagram_short("anagram", "nagaram"))  # True
```

## When to Reach for a Hash Map

Here are strong signals that a hash map will help:

| Clue in the Problem | Hash Map Use |
|---|---|
| "Find if something exists" | Store values for O(1) lookup |
| "Count occurrences" | Map items to their counts |
| "Find pairs/complements" | Store what you've seen so far |
| "Group items by property" | Map property to list of items |
| "Remove duplicates" | Use a set (a hash map without values) |
| "Find first/last occurrence" | Map values to indices |

**Time complexity cheat sheet:**
- Looking up a key: **O(1)** average
- Adding a key-value pair: **O(1)** average
- Deleting a key: **O(1)** average
- Iterating all keys: **O(n)**

**Space complexity:** O(n) — you're using extra memory to store the map. This is almost always a worthwhile trade-off for the speed gain.

## Key Takeaways

- Hash maps (Python dicts) give you O(1) lookups — they turn O(n²) brute-force solutions into O(n) elegant ones
- The three most common hash map patterns are: counting occurrences, storing complements for pair-finding, and tracking indices of seen values
- The .get(key, default) method is your friend — it avoids KeyError by returning a default value when the key doesn't exist
- When a problem says 'find', 'count', 'pair', or 'duplicate', your first instinct should be to consider a hash map
