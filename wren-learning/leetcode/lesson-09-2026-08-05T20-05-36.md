## What Is a Linked List?

Imagine a scavenger hunt where each clue tells you where to find the next clue. That's essentially a **linked list** — a chain of items where each item (called a **node**) holds two things:

1. **A value** (the data itself)
2. **A pointer to the next node** (directions to the next item)

The first node is called the **head**. The last node points to `None` (meaning "there's nothing after me").

**How is this different from an array?**

| Feature | Array | Linked List |
|---------|-------|-------------|
| Access element by index | ✅ Fast (O(1)) | ❌ Slow (O(n)) — must walk through |
| Insert at beginning | ❌ Slow (O(n)) — must shift everything | ✅ Fast (O(1)) |
| Memory | Stored together in a block | Scattered, connected by pointers |

Linked lists shine when you need frequent insertions/deletions but don't need random access.

## Building a Linked List from Scratch

```python
# Step 1: Define what a single node looks like
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val    # The data this node holds
        self.next = next  # Pointer to the next node

# Step 2: Create nodes
node1 = ListNode(1)
node2 = ListNode(2)
node3 = ListNode(3)

# Step 3: Link them together
node1.next = node2
node2.next = node3
# node3.next is already None (end of list)

# The chain: 1 -> 2 -> 3 -> None

# Step 4: Traverse (walk through) the linked list
def print_list(head):
    current = head
    while current is not None:
        print(current.val, end=" -> ")
        current = current.next  # Move to the next node
    print("None")

print_list(node1)  # Output: 1 -> 2 -> 3 -> None
```

## The Key Skill: Traversing a Linked List

Unlike arrays where you use `for i in range(len(arr))`, with linked lists you **follow the chain**:

```
current = head
while current is not None:
    # do something with current.val
    current = current.next
```

This is the **most important pattern** to memorize. Almost every linked list problem starts with some form of traversal.

**Common mistakes beginners make:**
- ❌ Trying to use `list[i]` — linked lists don't support indexing
- ❌ Forgetting to move forward (`current = current.next`), causing an infinite loop
- ❌ Accessing `.val` or `.next` on `None`, causing a crash

**Golden rule:** Always check `if current is not None` before accessing `current.val` or `current.next`.

## LeetCode #206: Reverse Linked List

**Problem:** Given the head of a linked list, reverse the list and return the new head.

```
Input:  1 -> 2 -> 3 -> 4 -> 5 -> None
Output: 5 -> 4 -> 3 -> 2 -> 1 -> None
```

**The analogy:** Imagine people standing in a line, each pointing forward to the person in front of them. To reverse the line, you need each person to turn around and point backward instead.

**Strategy (iterative approach):**
We walk through the list and flip each arrow one at a time. We need three variables:

- `prev` — the node behind us (starts as `None`)
- `current` — the node we're currently at
- `next_node` — temporarily saves the next node before we flip the arrow

**Step-by-step for [1, 2, 3]:**
1. At node 1: flip arrow to point at `None`. Move forward.
2. At node 2: flip arrow to point at 1. Move forward.
3. At node 3: flip arrow to point at 2. Move forward.
4. `current` is now `None`, so `prev` (node 3) is the new head!

## Solution: Reverse Linked List

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverseList(head):
    prev = None
    current = head
    
    while current is not None:
        next_node = current.next  # Save the next node
        current.next = prev       # Flip the arrow!
        prev = current             # Move prev forward
        current = next_node        # Move current forward
    
    return prev  # prev is now the new head

# --- Test it ---
# Build: 1 -> 2 -> 3 -> None
head = ListNode(1, ListNode(2, ListNode(3)))

# Reverse it
new_head = reverseList(head)

# Print result
current = new_head
while current:
    print(current.val, end=" -> ")
    current = current.next
print("None")
# Output: 3 -> 2 -> 1 -> None

# Time complexity: O(n) — we visit each node once
# Space complexity: O(1) — we only use a few variables
```

## Key Takeaways

- A linked list is a chain of nodes where each node holds a value and a pointer to the next node — unlike arrays, you can't jump to a specific index
- Traversal is the core skill: use `while current is not None` and advance with `current = current.next`
- Reversing a linked list uses three pointers (prev, current, next_node) to flip each arrow one at a time — this is one of the most commonly asked interview problems
- Always guard against accessing `.val` or `.next` on `None` to avoid crashes
