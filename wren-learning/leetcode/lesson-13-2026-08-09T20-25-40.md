## What Is a Stack?

Imagine a stack of plates in a cafeteria. You can only add a plate on **top**, and you can only remove the plate from the **top**. You can't pull one from the middle.

This is exactly how a **stack** works in programming:
- **Push**: Add an item to the top
- **Pop**: Remove the item from the top
- **Peek**: Look at the top item without removing it

This behavior is called **LIFO** — Last In, First Out. The last thing you put in is the first thing you take out.

In Python, a regular list works perfectly as a stack:
- `stack.append(x)` → push
- `stack.pop()` → pop
- `stack[-1]` → peek

## Stack Basics in Python

```python
# Using a Python list as a stack
stack = []

# Push items
stack.append('A')
stack.append('B')
stack.append('C')
print(stack)  # ['A', 'B', 'C']  — C is on top

# Peek at the top
print(stack[-1])  # 'C'

# Pop items (removes from top)
top = stack.pop()
print(top)    # 'C'
print(stack)  # ['A', 'B']  — now B is on top

# Check if stack is empty
print(len(stack) == 0)  # False
```

## The Problem: Valid Parentheses (LeetCode #20)

**Problem**: Given a string containing just the characters `(`, `)`, `{`, `}`, `[`, and `]`, determine if the input string is valid.

A string is valid if:
1. Every open bracket has a matching close bracket of the **same type**
2. Brackets are closed in the **correct order**

**Examples:**
- `"()"` → `True` ✅
- `"()[]{}"` → `True` ✅
- `"(]"` → `False` ❌ (wrong type)
- `"([)]"` → `False` ❌ (wrong order)
- `"{[]}"` → `True` ✅ (nested correctly)

**Why is a stack perfect here?** Think about it: when you see a closing bracket, it must match the **most recent** unmatched opening bracket. "Most recent" = "last in" = exactly what a stack tracks!

## The Strategy: Think Like a Proofreader

Imagine you're proofreading a math equation and checking that all brackets match. Here's your mental process:

1. You scan left to right
2. When you see an **opening bracket** `(`, `[`, or `{` — you remember it (push onto your mental stack)
3. When you see a **closing bracket** `)`, `]`, or `}` — you check: does it match the last opening bracket I remember?
   - **Yes** → Great, forget that opening bracket (pop it off)
   - **No** → Error! The brackets don't match
4. At the end, if you're still remembering unmatched opening brackets → Error!

**Walkthrough with `"{[]}"`:**

| Character | Action | Stack |
|-----------|--------|-------|
| `{` | Push | `[{]` |
| `[` | Push | `[{, []` |
| `]` | Pop `[`, matches! | `[{]` |
| `}` | Pop `{`, matches! | `[]` |
| End | Stack empty → Valid! | ✅ |

## Solution: Valid Parentheses

```python
def isValid(s: str) -> bool:
    # Map each closing bracket to its matching opening bracket
    matching = {
        ')': '(',
        ']': '[',
        '}': '{'
    }
    
    stack = []
    
    for char in s:
        if char in matching:
            # It's a closing bracket
            # Check if stack is empty OR top doesn't match
            if not stack or stack[-1] != matching[char]:
                return False
            stack.pop()  # Remove the matched opening bracket
        else:
            # It's an opening bracket — push it
            stack.append(char)
    
    # Valid only if all opening brackets were matched
    return len(stack) == 0

# Test cases
print(isValid("()"))       # True
print(isValid("()[]{}"))   # True
print(isValid("(]"))       # False
print(isValid("([)]"))     # False
print(isValid("{[]}"))     # True
print(isValid("("))        # False (unmatched opening)
print(isValid(")"))        # False (closing with empty stack)
```

## Breaking Down the Solution

Let's understand each piece:

**The matching dictionary**: Instead of writing messy if-else chains, we store the relationship: `')' → '('`. When we see `)`, we look up what it *should* match.

**The two cases for each character:**
- **Opening bracket** (`(`, `[`, `{`): Just push it. We'll deal with it later.
- **Closing bracket** (`)`, `]`, `}`): Check immediately — does the top of the stack have the right match?

**Two ways to fail with a closing bracket:**
1. Stack is empty → there's nothing to match with (e.g., input is `")"`) 
2. Top of stack is wrong type → mismatched brackets (e.g., `"(]"`) 

**The final check**: `len(stack) == 0` catches cases like `"(("` where we have leftover unmatched opening brackets.

**Time complexity**: O(n) — we look at each character once
**Space complexity**: O(n) — in the worst case, we push every character (e.g., `"(((("`)

## Key Takeaways

- A stack is a Last-In-First-Out (LIFO) structure — in Python, use a list with append() and pop()
- Stacks are the natural choice when you need to match things with the 'most recent' unmatched item — like bracket matching
- The Valid Parentheses problem uses three key checks: matching type, non-empty stack when closing, and empty stack at the end
- Using a dictionary to map closing brackets to opening brackets keeps your code clean and avoids complex if-else chains
