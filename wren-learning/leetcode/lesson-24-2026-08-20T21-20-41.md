## What Is Backtracking?

Imagine you're at a buffet and you want to figure out **every possible plate combination** you could make. You might:

1. Start with an empty plate
2. Add salad → record that combination
3. Add soup on top → record that combination
4. Add dessert on top → record that combination
5. **Remove dessert** (backtrack) → try the next item instead
6. **Remove soup** (backtrack) → try the next item instead
7. Keep going until you've tried everything

This "choose, explore, un-choose" pattern is **backtracking**. It's a refined form of recursion where:

- You **make a choice** (add an element)
- You **recurse** deeper to explore what follows
- You **undo the choice** (remove the element) before trying the next option

Backtracking is used for problems involving:
- All subsets (power set)
- All permutations
- Combinations that meet constraints
- Sudoku solvers, N-Queens, and more

## The Problem: Subsets (LeetCode #78)

**Problem:** Given an integer array `nums` of unique elements, return all possible subsets (the power set).

Example:
- Input: `nums = [1, 2, 3]`
- Output: `[[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]]`

For a set of size `n`, there are `2^n` subsets. Why? For each element, you have **two choices**: include it or exclude it. With 3 elements, that's `2 × 2 × 2 = 8` subsets.

**Think of it like a decision tree:**
```
                    []
           /                 \
       include 1          skip 1
        [1]                  []
       /    \             /     \
   inc 2   skip 2     inc 2   skip 2
   [1,2]    [1]       [2]      []
   / \      / \      / \      / \
inc3 sk3  i3  s3   i3  s3   i3  s3
```
Every **leaf** of this tree is a valid subset!

## Solution: Backtracking Approach

```python
def subsets(nums):
    result = []
    
    def backtrack(start, current_subset):
        # Every state is a valid subset, so record it
        result.append(current_subset[:])  # append a COPY
        
        # Try adding each remaining element
        for i in range(start, len(nums)):
            # CHOOSE: add nums[i] to our subset
            current_subset.append(nums[i])
            
            # EXPLORE: recurse with the next starting index
            backtrack(i + 1, current_subset)
            
            # UN-CHOOSE (backtrack): remove nums[i]
            current_subset.pop()
    
    backtrack(0, [])
    return result

# Test it
print(subsets([1, 2, 3]))
# Output: [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
```

## Step-by-Step Walkthrough

Let's trace through `subsets([1, 2, 3])`:

| Call | start | current_subset | Action |
|------|-------|---------------|--------|
| 1 | 0 | `[]` | Record `[]`. Try i=0,1,2 |
| 2 | 1 | `[1]` | Record `[1]`. Try i=1,2 |
| 3 | 2 | `[1,2]` | Record `[1,2]`. Try i=2 |
| 4 | 3 | `[1,2,3]` | Record `[1,2,3]`. No more items. |
| — | — | `[1,2]` | **Backtrack**: pop 3 |
| — | — | `[1]` | **Backtrack**: pop 2 |
| 5 | 3 | `[1,3]` | Record `[1,3]`. No more items. |
| — | — | `[1]` | **Backtrack**: pop 3 |
| — | — | `[]` | **Backtrack**: pop 1 |
| 6 | 2 | `[2]` | Record `[2]`. Try i=2 |
| 7 | 3 | `[2,3]` | Record `[2,3]`. No more items. |
| — | — | `[2]` | **Backtrack**: pop 3 |
| — | — | `[]` | **Backtrack**: pop 2 |
| 8 | 3 | `[3]` | Record `[3]`. No more items. |

**Key insight:** `start` ensures we only look **forward** in the array, avoiding duplicate subsets like `[2,1]` (since `[1,2]` already exists).

**Why `current_subset[:]`?** We append a **copy** because `current_subset` keeps changing. Without the copy, all entries in `result` would point to the same (eventually empty) list.

## The Backtracking Template

```python
# This template works for MANY backtracking problems!

def backtracking_template(input_data):
    result = []
    
    def backtrack(state, choices):
        # Base case: if the state is a valid solution, record it
        if is_solution(state):
            result.append(state[:])
            return
        
        for choice in choices:
            # Optional: skip invalid choices
            if not is_valid(choice):
                continue
            
            # CHOOSE
            state.append(choice)   # or modify state
            
            # EXPLORE
            backtrack(state, updated_choices)
            
            # UN-CHOOSE
            state.pop()            # undo the modification
    
    backtrack(initial_state, all_choices)
    return result

# For subsets: every state is a solution (no base case filter needed)
# For permutations: only when len(state) == len(nums)
# For combinations of size k: only when len(state) == k
```

## Key Takeaways

- Backtracking follows a 'choose → explore → un-choose' pattern that systematically explores all possibilities
- The `start` parameter prevents revisiting earlier elements, which avoids generating duplicate subsets
- Always append a copy (`current_subset[:]`) to results — not the original list, which keeps mutating
- For subsets, every node in the decision tree is a valid answer (2^n total), unlike permutations where only leaves count
- The backtracking template (choose, explore, un-choose) can be adapted for subsets, permutations, combinations, and constraint-satisfaction puzzles
